# 💎 DYNEVEST | Crypto Mining & Fintech Platform

**DYNEVEST** is a robust, full-stack fintech application designed to bridge the gap between users and crypto-mining profitability. Built with Django and Bootstrap, it offers a seamless experience for managing mining plans, tracking earnings, and processing financial transactions.

## 🚀 Features

*   **User Authentication:** Secure registration and login system with persistent sessions.
*   **Dynamic Dashboard:** Real-time visualization of account balances, profits, and active mining power.
*   **Mining Plan Management:** Users can browse and "purchase" mining plans that interact with their account balance.
*   **Transaction Tracking:** A complete ledger system recording deposits, withdrawals, and plan activations.
*   **Responsive UI:** Mobile-first design using Bootstrap 5 for a premium user experience.

## 🛠️ Tech Stack

*   **Backend:** Python 3.13+, Django 6.0
*   **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
*   **Database:** SQLite (Development) / PostgreSQL (Production ready)
*   **Architecture:** Model-View-Template (MVT)
